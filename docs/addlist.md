수정 및 추가기능
1. QR코드 연결 시 wifi direct까지 자동으로 한번에 연결 되게하고, 사용자는 신경안쓰게 해준다. 단 wifi LAN의 경우에는 직접 고를 수 있는 작업을 남겨둔다.
2. Bluetooth 장비 찾기 탭과 wi-fi direct창도 비활성화 해준다
3. 기기가 오프라인인 경우 오프라인을 보여주고 다른 기능을 비활성화 시켜준다
4. 기기연결상태는 WIFI와 연결 or 미연결 이 두상태로 나뉘게 바꿔준다 사용자는 다른 불필요한 문구를 제외시켜준다 ex)서버 업로드 비활성...
5. 빠른 작업탭의 경우
   - WI-FI설정 에 부연설명을 사용할 공유기에 연결로 변경
   - WIFI-DIRECT -> 삭제
   - 저장소 탐색 -> 저장 데이터 확인
   - 서버업로드 -> 업로드 확인 (업로드 중이 아닌경우 비활성화 후 문구는 업로드중이 아닙니다)
   - 자동 실행 작업 -> 사용 가능한 작업목록
6. 관리자 작업 -> 장치 제어
7. 장치제어에서 추가로 FAN속도 조절과 사용자가 직관적으로 알아볼 수 있는 기능 추가할 것이 있다면 추가해줘
8. 기기 재부팅 후 BLE로 자동 앱과 붙으면 오프라인에서 온라인으로 변경될 수 있게 해줘
9. 업로드에 성공한 데이터는 사용자가 확인 후 삭제할 수 있게 하는 기능 추가 (이 때 서버에 올라간 리스트와 대조해서 실패했던것들은 재업로드 할 수 있는 기능 추가)
10. 서버의 업로드 후 폴더명으로 확인할 수 있게 변경
11. 업로드 시 예상 시간과 실시간으로 몇 mb가 전송되고 있는지 확인할 수 있게 변경
12. python작업 목록 추가 시 폴더만 지정하면 나머지는 자동으로 설정할 수 있게함 대신 .venv 가상환경과 yaml과 main으로 실행해야할 규칙들은 docs로 만들어서 어떤 규칙을 가지게 폴더를 구성하라고 명시 -> 사용자는 작업 이름만 지정하게 되면 로그, 설정, 출력(결과로 이름변경해줘)이 지금처럼 나올 수 있게 해주고 부팅 시 실행도 사용자가 추가하면 장치에 등록 될 수 있게 해줘
13. 시스템 시간을 모바일에서 가져와서 동기화 한 후 작업들을 시작할 수 있게 변경해줘
14. GNSS위치 디버깅의 경우 모바일에서의 값과 장치의 값 두가지로 보여주고 만약 장치가 꺼져있거나 모바일이 꺼져있다면 상태를 알 수 있게 해줘
15. GPS상태의 경우 DGPS, RTK FLOAT등 이렇게 나타내지말고 RTK가 잡혔는데 FLOAT이면 RTK신호가 약합니다 RTK가 꺼져있습니다 RTK 수신중 이렇게 나타내주고 GNSS 마저 꺼져있는경우 GNSS 장치가 꺼져있습니다 이렇게 4가지 상태로 나타내줘
16. 자동 실행 작업 밑에 부연설명들은 모두 지워줘
17. 업로드 전 폴더의 용량을 계산해서 업로드 탭에서 볼 수 있게 해줘
