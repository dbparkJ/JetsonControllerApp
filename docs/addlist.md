1. ~~알람 아이콘을 메인화면에 만들어서 알람내역들을 볼 수 있게하고 터치시 그 해당하는 작업 탭으로 넘어 갈 수 있게 해줌~~
   - 처리: 메인 화면과 대시보드에 읽지 않은 개수 배지가 있는 알림 아이콘을 추가했다. 장비 상태, 파이프라인, 업로드 알림을 최대 100개까지 저장하고 알림을 누르면 저장소, 센서, 작업, 업로드 화면으로 이동한다. 개별 삭제, 모두 읽음, 전체 삭제도 지원한다.
   - 확인: SM-S908N에서 알림 아이콘과 알림 내역 화면을 확인했고, 알림 목적지 이동 계측 테스트를 통과했다.

2. ~~ble로 연결 한 후 wifi다이렉트로 연결하려고 하면 무한 팅김현상~~
   - 처리: 기존 연결 상태만으로 대시보드를 자동으로 여는 로직을 제거하고 사용자가 요청한 연결 방식이 실제로 완료된 경우에만 이동하도록 변경했다. IP 연결이 성공하기 전에는 BLE를 유지하고, 성공한 뒤 BLE 세션을 정리하도록 전환 순서도 수정했다.
   - 확인: SM-S908N에서 Bluetooth 연결 후 대시보드의 Wi-Fi Direct로 이동해 MMS-4DE0 피어 연결과 Wi-Fi Direct 대시보드 진입까지 완료했다.

3. ~~장치하나 연결 후 뒤로가기 눌러도 메인으로 가지지 않고 계속 장치 대시보드로 넘어감~~
   - 처리: 대시보드 뒤로가기와 연결 해제가 명시적으로 메인 연결 화면으로 돌아가며, 이미 연결된 상태만으로 대시보드를 다시 여는 동작을 제거했다.
   - 확인: Wi-Fi Direct 대시보드에서 뒤로가기를 누른 뒤 3.5초 이상 메인 화면이 유지되는 것을 실기기에서 확인했다.

4. ~~대시보드에 알람 화면을 끌 수 있게 해줘야함 ex) 확인이 필요합니다 끌 수 있게~~
   - 처리: `확인이 필요합니다` 상태 카드에 닫기 버튼을 추가했다. 현재 문제 조합은 숨기되 온도, 저장공간, 실패 작업 등 문제 내용이 달라지면 새 알림으로 다시 표시한다.
   - 확인: 경고 카드를 닫은 뒤 화면에서 사라지는 계측 테스트를 추가해 통과했다.

5. ~~대쉬보드에서 wifi-driect를 눌러도 무한 팅김~~
   - 처리: Wi-Fi Direct 화면 진입만으로 기존 LAN 또는 BLE 연결이 대시보드 이동을 재발생시키지 않도록 내비게이션 조건을 분리했고, 검색과 연결 요청의 중복 실행도 차단했다.
   - 확인: Wi-Fi Direct 연결 대시보드의 빠른 작업에서 Wi-Fi Direct를 누른 뒤 연결 화면이 3.5초 이상 유지되는 것을 실기기에서 확인했다.

6. ~~LAN연결과 WIFI-direct 연결 구분이 안됨, LAN연결 시 서버에 업로드는 비활성화해야함~~
   - 처리: 대시보드 상단에 LAN, Wi-Fi Direct, Bluetooth 연결 방식과 엔드포인트를 명확히 표시한다. 서버 업로드 시작 및 재시도는 Wi-Fi Direct에서만 허용하고, LAN에서는 화면 버튼과 저장소 업로드 진입을 비활성화했으며 저장소 계층 아래에서도 저장소 정책을 재검증한다.
   - 확인: 연결 방식 및 업로드 정책 단위 테스트와 앱 lint를 통과했고, 실기기 Wi-Fi Direct 화면에서 서버 업로드 활성 상태를 확인했다.

7. ~~wifi-direct시 재부팅과 종료가 안되는현상~~
   - 처리: Jetson 운영 설정에 `allow_power_commands=true`를 반영하고 제어 API와 Wi-Fi Direct 서비스를 재배포했다. Wi-Fi Direct API 연결이 성립하면 서버 기능 정보에 따라 재부팅과 종료 버튼이 활성화된다.
   - 확인: 실기기 Wi-Fi Direct 대시보드에서 재부팅과 종료 버튼이 활성화된 것을 확인했다. 작업 장비를 실제로 끄지 않고 `systemctl reboot`와 `systemctl poweroff` 예약 경로를 단위 테스트로 검증했다.

작업 완료 버전: Android 앱 1.9.0 (versionCode 11), Jetson Controller backend 1.6.0
