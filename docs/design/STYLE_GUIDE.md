# 현재 색상·컴포넌트 설명

색상 기준은 [colors.json](colors.json)과 앱 `ui/theme/Color.kt`다. V5/V7 제작 패키지는 제거되었으며 실제 앱에서 사용하던 색상 값은 그대로 보존되어 있다.

라이트 모드는 차가운 오프화이트 바탕과 짙은 회색 글자, 다크 모드는 차콜 바탕과 밝은 회색 글자를 사용한다. 기본·보조·강조 섹션은 같은 색상 계열에서 명도 차이로 구분된다. 주요 행동과 선택 상태는 저채도 슬레이트 블루, 경고·실패는 기존 의미색을 사용한다.

| 역할 | Light | Dark |
|---|---|---|
| 바탕 | `#F4F5F7` | `#1C1E22` |
| 표면 | `#FBFCFD` | `#25282D` |
| 본문 | `#272C32` | `#E4E6EA` |
| 보조 본문 | `#525862` | `#ABB0B7` |
| 현재 작업 | `#E0E7F1` | `#333B48` |

홈 상단은 장치 사진과 실제 지표, 다음 섹션은 현재 작업과 빠른 기능이다. 설정의 장비 사진·아이콘 행은 같은 섹션 색상과 도형을 사용하며 위험 동작은 `dangerBg`와 오류색 버튼으로 구분된다. 상태 이름과 아이콘이 함께 표시되므로 색만으로 상태를 구분하지 않는다.

본문 글꼴과 테마 설정은 기존 Compose 테마를 따른다. 파일 목록은 탐색·날짜 구분·유형 필터를 사용하고 전송 버튼과 미리보기를 유지한다. 화면 크기에 따라 가로 필터는 스크롤되며 긴 내용은 세로 목록에 표시된다.

`scripts/check_slate_harmony.py`는 실제 색상 소스와 보관된 토큰의 일치 및 선언된 글자·배경 조합의 대비를 검사한다. 이 검사는 모든 렌더링 상태의 접근성 인증을 의미하지 않는다.
