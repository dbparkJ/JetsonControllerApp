## 기준과 최종 원본

2026-09-15에 실제 연결된 휴대폰의 `phone-before-*.png`를 기준으로 한다. `images/지금 버전/`과 태블릿의 기존 설치 화면은 현재 UI 기준이 아니다. 태블릿은 동일한 새 APK로 검증한다.

색상은 사용자 제공 가이드와 일치하는 `ui/theme/Color.kt`의 `GeoLight`·`GeoDark`, `GeoPalette.kt`가 기준이다. Primary는 라이트 `#2550A3`, 다크 `#8FAEE4`다. [STYLE_GUIDE.md](STYLE_GUIDE.md)와 [colors.json](colors.json)은 현행 값을 반영하며 과거 Slate 값으로 되돌리지 않는다. 글꼴·굵기·크기·행간은 `ui/theme/Type.kt` 그대로 유지한다. Android SansSerif, Roboto/Noto Sans KR 대체 글꼴과 tabular figures를 사용한다.

## 페이지별 구현 규칙

1. **탐색:** 홈 / 파일 / 설정 세 곳. 조사 이력은 홈 최근 수집과 이력 진입에 유지한다. 장치·연결·알림을 간결하게 표시하고 좁은 화면에서 추가 도구는 메뉴로 보낸다.
2. **홈:** 장치 사진으로 제어 대상을 표시하고 현재 작업에 맞는 행동 하나를 강조한다. 긴 고정 교육 문구를 붙이지 않는다. 진행 중·시작 미확인은 새 수집보다 우선한다.
3. **준비:** 작업, 프로젝트, 구간, 점검을 순서대로 구성한다. 프로젝트 선택 시트의 추가 항목과 구간 제목 옆 추가 동작으로 기존 생성 기능을 유지한다. 정책·경로·실행 설정은 개발자 모드에 둔다.
4. **수집:** 조사·장치 식별, 수집 상태, 마지막 확인, 카메라·위치, 종료를 보존한다. API가 시간을 제공하지 않으면 `—`다. 위치가 없으면 `위치 정보 대기`를 표시하며 허구 지도 경로를 그리지 않는다. 일시정지는 추가하지 않는다.
5. **결과:** 수집 종료, 장치 저장, 서버 수신을 독립된 행으로 표시한다. 서버 수신 미확인을 미전송이라고 단정하지 않는다. 종료된 실행을 버리지 않고 결과를 유지한다.
6. **파일:** pipeline 별칭 메뉴가 아닌 실제 storage entries를 탐색한다. 기본 모드에서 폴더 행을 누르면 연다. `선택`으로 선택 모드에 들어가 파일 또는 폴더 **하나**를 선택한다. `취소`/`선택 해제`를 제공한다. 기존 `(rootId, path)` 단일 대상 API를 사용하며 폴더는 내부 전체를 전송한다. 다중 선택·배치 전송을 추가하지 않는다. 선택이 없으면 비활성 전송 바와 빈 상세 열을 숨긴다.
7. **설정:** 일반 네트워크(Wi-Fi), 테마, 알림, 도움말, 앱 정보와 기본 꺼짐 개발자 스위치를 그룹 행으로 제공한다. 고정 주요 CTA를 두지 않는다. 도움말은 실제 열리고 닫히는 시트다.

## 태블릿과 큰 글꼴

| 화면 | 800dp 노드 | 1333dp 노드 | 넓은 화면 구성 |
|---|---|---|---|
| 홈 | `37:2` | `37:1110` | 장치·작업 / 현황·최근 수집 표 |
| 수집 중 | `37:1090` | `37:1153` | 지도·관찰 / 상태·카메라·종료 |
| 파일 | `37:1100` | `37:1196` | 위치 / 실제 목록 / 선택 상세 |
| 설정 | `44:391` | `44:545` | 장치·앱 설정 / 정보·개발자 모드 |

- 휴대폰은 411dp 기준, 바깥 20dp, 한 열이다. 360dp와 글꼴 1.0·1.1·2.0에서도 검사한다. 제목·메타데이터·버튼 높이는 내용에 맞게 늘리고 줄바꿈을 허용한다. 주요 버튼 최소 52dp, 터치 대상 최소 48dp다.
- 800dp는 바깥 24dp, 간격 24dp, 하단 탐색이다. 홈 두 열은 각 364dp. 파일은 위치 156dp + 목록 572dp이며 선택할 때만 간결한 하단 전송 제어를 표시한다.
- 1333dp는 레일 88dp, 내용 바깥 24dp다. 홈 왼쪽 380dp/오른쪽 793dp; 수집 관찰 743dp/제어 430dp; 파일 위치 180dp/목록 617dp/선택 상세 352dp다. 이는 해당 참조 너비의 배분이며 고정 픽셀 규칙이 아니다.
- 파일 상세에 전송·선택 해제를 넣어 가로 화면 전체 폭의 빈 하단 바를 만들지 않는다. 선택이 없으면 상세 열을 숨기고 목록을 확장한다. 라디오 등 trailing control은 목록 오른쪽 여백에 정렬한다.
- 글꼴이 200%이거나 실제 가용 폭이 부족하면 두 열·표를 한 열로 접는다. 표 보조 값은 행 아래로 내려가며 필수 상태를 생략하지 않는다. 조작 도구·탭을 고정 높이로 자르지 않는다.
- 라이트/다크는 동일 의미 토큰을 사용한다. 성공·주의·미확인 등은 색상과 함께 이름·아이콘으로 전달한다.

## 개발자 모드와 안내 수명

기본 화면에는 현장 행동과 사용자 상태를 남긴다. IP/포트/프로토콜, 원시 예외, pipeline 편집·entrypoint·revision·run ID, 출력 경로, endpoint, 로그·터미널, 시스템 계측·팬·전원은 개발자 모드에서만 표시한다. 일반 Wi-Fi 연결은 기본 설정에 남긴다. 모드가 꺼지면 기술 진입점과 화면 내부 상세를 모두 숨긴다. UI 스위치를 서버 권한으로 취급하지 않으며 기존 대상 확인·파괴적 동작 보호를 유지한다.

도움말은 닫을 수 있고 닫힘을 기억한다. 완료 알림은 일시적으로 표시한다. 실제 연결 끊김·시작 응답 대기·점검 실패는 해당 조건 동안 표시하고 해결되면 사라진다. 원시 소켓 오류 대신 짧은 한국어 상태와 재시도 등 행동을 제공한다. 앱 연결 끊김을 장치 수집 종료로 해석하지 않는다.

## 구현 단계와 완료 조건

1. 기존 색상·타입·브랜드 자산을 유지하며 세 항목 탐색과 적응형 셸을 적용한다.
2. 연결·홈·준비·점검·시작 대기·수집·종료·결과를 화면별 구조로 구현하고 종료 결과와 미확인 상태를 보존한다.
3. 실제 파일 탐색·단일 선택 전송, 그룹형 설정과 개발자 모드, 일반 Wi-Fi와 닫을 수 있는 도움말을 적용한다.
4. 영향받는 JVM 테스트, assemble/lint, 색상 검사를 수행한다. 동일 새 APK의 휴대폰·태블릿에서 라이트/다크, 일반/200% 글꼴을 캡처해 Figma와 비교한다. UI 검증을 위해 실제 센서 수집·전송·전원을 임의 실행하지 않는다.

완료 기준: 페이지마다 역할에 맞는 구조와 명확한 행동이 있음; 기본 화면에서 기술 정보가 숨겨짐; 필요한 기존 기능에 계속 접근 가능; 연결·수집·저장·수신을 혼동하지 않음; 도움말을 닫을 수 있음; 큰 글꼴에서 필수 상태·행동·탐색이 잘리지 않음; 태블릿이 단순히 늘린 휴대폰 화면이 아님.
