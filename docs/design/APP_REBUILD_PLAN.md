# 현장 앱 UX 개선 작업 계획

## 기준과 원본

사용자가 지정한 동일 [Figma 파일](https://www.figma.com/design/cUWQCtpNuh9jhRomfMOvYC?node-id=28-451)을 계속 수정한다. 이전 단순 와이어프레임 Archive 페이지 2:5·2:6은 삭제했고, 최신 Phone·Tablet 페이지와 기존 진입 노드 28:451은 유지했다.

색상은 사용자 가이드와 일치하는 `GeoLight`·`GeoDark`·`GeoPalette.kt`, 글꼴·굵기는 기존 `Type.kt`가 기준이다. 휴대폰 타입 크기는 유지한다. 태블릿만 앱 내부에서 글자·아이콘을 약 1.10배 키운다. 단말의 시스템 글꼴 설정은 변경하지 않는다. 홈의 회사 로고와 장치 이미지는 변경하지 않는다.

실제 기준 화면은 `.mobile-build/rebuild-20260915/final-{phone,tablet}-actual-*.png`와 `.mobile-build/refinements-20260915/phone-before-{history,map}.png`다. 과거 `images/지금 버전/`은 현재 기준이 아니다. Figma의 시간·용량·비율·파일명은 배치 검토용 예시이며 앱에서는 실제 값만 표시한다.

## 1. 탐색과 홈

하단 탐색은 **홈 / 수집 / 파일 / 설정** 순서다. Material Home / PlayCircle / FolderOpen / Settings를 사용한다. 수집 탭은 현재 수집·응답 미확인이 있으면 해당 화면으로 돌아가고, 없으면 수집 준비를 연다.

홈 제목은 `홈`이다. 장치 사진과 회사 로고는 유지한다. 저장 공간과 현재 수집을 각각 저장 장치·수집 아이콘이 있는 독립 영역으로 표시한다. 관련 업로드가 있으면 진행 중 작업을 우선 표시하고, 없으면 가장 최근 완료·실패 결과를 표시한다. 요약을 눌러 업로드 목록으로 이동한다. 오래된 전체 이력을 홈에 쌓지 않는다.

## 2. 수집과 결과

- 프로젝트·구간을 깔끔하게 표시하고 불필요한 장치 제어 설명을 제거한다.
- 수집 중에는 **경과 시간 / 수집 용량 / 최근 확인**을 표시한다. API 미제공 값은 `—` 또는 `확인 중`이며 앱이 임의로 시간을 생성하지 않는다.
- 파일·결과 정보를 한 영역에 모으고 `저장 폴더`라고 명명한다.
- `홈으로`를 `수집 종료` 바로 위에 배치한다. 종료 대상 확인과 장치 응답 확인을 유지한다. 일시정지는 추가하지 않는다.
- 결과는 **수집 시간 / 수집 용량 / 정밀 위치**의 세 지표와 종료·장치 저장·서버 수신의 독립 상태를 표시한다. 수신 미확인을 미전송으로 단정하지 않는다.
- 준비 화면의 프로젝트 추가·구간 추가, 점검과 시작 확인, 응답 대기 시 동일 요청 확인을 보존한다.

## 3. 지도와 일반 사용자 요약

기본 지도 위의 큰 품질 설명을 제거한다. 지도는 남는 공간을 채우고, 품질 요약은 하단 버튼보다 위의 별도 영역에 둔다. 시스템 탐색 영역과 겹치지 않는다. 가로 태블릿에서는 지도와 품질·행동을 두 열로 배치한다.

- 실제 관찰 횟수·확인 시간·미확인 시간을 짧게 표시한다. 품질 변화는 작은 누적 막대와 실제 경로의 의미색으로 표현한다.
- 새 위치 정밀도 데이터가 있으면 `정밀 위치`, `대략 위치`, `위치 없음`을 구분한다. 누락은 `미확인`이다. 정상 사용 화면에 FIX/FLOAT/GNSS 같은 원시 코드를 쓰지 않는다.
- 과거 데이터의 `관찰 시간 - 정밀 시간`에는 위치가 없었던 시간이 포함될 수 있다. 이 값은 **정밀 위치 외**라고 표시하며 대략 위치라고 추정하지 않는다.
- 비율은 확인 가능한 관찰 시간 기준임을 명시하고 미확인 시간을 별도로 표시한다. 임의 관찰 개수나 판정 점수를 만들지 않는다.
- 일반 사용자는 `수집 요약`에서 주요 시각·상태 변화와 간단한 로그를 볼 수 있다. 원시 센서 코드·요구 조건·진단 로그는 개발자 모드에서만 펼친다.
- Figma의 지도 대기 화면은 실제 장치 위치가 없는 상태다. 앱의 정상 지도는 기존 MapLibre와 실제 경로를 유지한다. 허구 위치나 도로를 추가하지 않는다.

## 4. 이력·파일·설정

수집 이력에서 장치 홈 링크와 수동 새로고침 요구를 제거한다. 빈 화면은 새 수집을 안내한다. 첫 오른쪽 스와이프는 행 왼쪽에 붙은 빨간 휴지통을 드러내고, 두 번째 오른쪽 스와이프 또는 휴지통 누르기는 복원 가능한 휴지통으로 이동한다. 삭제된 항목은 휴지통에서 복원할 수 있다. 영구 삭제와 혼동하지 않는다.

파일 화면에서 눌러지는 장치 이름을 제거한다. `업로드 목록` 진입은 항상 제공한다. 실제 storage entries를 탐색하고 폴더 행을 누르면 연다. 선택 모드에서 파일 또는 폴더 하나만 선택하며, 취소·선택 해제를 제공한다. 기존 `(rootId, path)` 단일 대상 전송을 유지한다. 선택이 없으면 비활성 전송 바·빈 상세 열을 숨긴다.

설정은 네트워크·테마·알림·도움말·앱 정보의 그룹 행이다. 기본 화면에 개발자 스위치를 노출하지 않는다. **앱 정보 7회 탭**으로만 개발자 모드를 해제한다. 도움말은 닫을 수 있고 닫힘을 기억한다. 실제 오류·응답 대기 상태는 조건이 해소될 때 사라진다.

## 5. 태블릿과 큰 글꼴

휴대폰 411dp·360dp는 바깥 20dp, 태블릿은 바깥 24dp·열 간격 24dp다. 1333dp 레일은 88dp다. 태블릿 텍스트 크기·행간과 주요 아이콘은 기본의 1.10배이며 색상·서체·굵기는 유지한다. 기존 시스템 글꼴 0.8배 설정을 강제로 바꾸지 않는다.

넓은 홈은 장치·작업과 최근 이력을 나누고, 파일은 위치·목록·선택 상세를 나눈다. 수집은 지표·저장 폴더·안전 제어와 지도·카메라를 나눈다. 선택이 없으면 상세 열을 숨긴다. 글꼴 200%에서는 필요한 열을 접고 제목·메타데이터·버튼을 줄바꿈한다. 터치 영역 최소 48dp, 주요 버튼 최소 52dp이며 큰 글꼴에서는 높이를 늘린다. 안전 영역과 마지막 행·버튼 사이에 시스템 inset을 반영한다.

## 6. 런처 아이콘

[Figma 런처 구성](https://www.figma.com/design/cUWQCtpNuh9jhRomfMOvYC?node-id=67-1457)은 원본 `geo_logo.png` 왼쪽 회사 심볼을 그대로 사용한다. 새 로고를 그리지 않는다. 앱 홈의 기존 로고·장치 그림에는 적용하지 않는다.

- Adaptive foreground: [foreground.png](assets/launcher/foreground.png), 투명 432×432px = 108dp×4.
- Monochrome: [monochrome.png](assets/launcher/monochrome.png), 같은 알파 형태의 432×432px.
- Background: `#FFFFFF` 단색. 그림자·그라데이션 없음.
- 심볼: 108dp 캔버스에서 x32.5/y29, 43×50dp. 전체가 중앙 66dp 안전 원 안에 포함된다.
- 실제 마스크는 중앙 72dp 범위이며 [circle.png](assets/launcher/circle.png)·[squircle.png](assets/launcher/squircle.png)는 192×192px legacy 원본이다. mdpi48/hdpi72/xhdpi96/xxhdpi144/xxxhdpi192로 줄인다.
- 원본 export 노드: foreground67:1461, monochrome67:1885, circle67:1873, squircle67:1877.

## 구현 순서와 완료 조건

1. 네 항목 탐색·홈 업로드 요약·앱 정보 개발자 해제를 적용한다.
2. 실제 telemetry와 위치 정밀도 데이터를 연결하고 수집·결과·지도·일반 요약을 수정한다.
3. 이력의 복원 가능한 스와이프 삭제와 파일·업로드 진입을 정리한다.
4. 런처 자산을 적용하고 태블릿 1.10배 및 가로·세로 배치를 반영한다.
5. 영향받는 JVM/Python 테스트, assemble/lint, 색상 검사를 수행한다. 같은 APK로 휴대폰·태블릿의 라이트/다크·일반/200% 글꼴을 검증한다. UI 검토를 위해 실제 수집·전송·전원을 임의 실행하지 않는다.

완료 조건은 모든 필수 행동 접근 가능, 실제 수집 상태 보존, 미확인을 성공/실패로 오인하지 않음, 지도·품질·버튼의 겹침 없음, 휴지통 복원 가능, 개발자 원시 정보의 기본 숨김, 큰 글꼴과 회전에서 잘림 없음이다.
