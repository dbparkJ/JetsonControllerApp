# PM Agent 평가

AG01~AG07 실행 보고서와 Astra 검수서를 모두 읽는다.

평가:
- PM 결정 누락/충돌
- Agent간 API/schema/state 충돌
- UI와 backend의 실제 연결 누락
- 시연 마감 필수와 운영 후속 분리
- Orin NX/Android/태블릿 실기 필요 항목
- 실시간 검지/geofence가 현재 scope에 섞였는지
- merge 순서와 충돌
- 다음 cycle의 Agent별 후속 지시

출력: `docs/agent-runs/PM_CYCLE_XX_EVALUATION.md`

Astra FAIL을 임의 승인하지 않는다. 최종 승인자는 인간 PM이다.
