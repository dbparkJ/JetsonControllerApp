# V4 → V5 변경 사항

## 유지

홈·작업·데이터·설정 4탭, 작업 우선 정보 위계, 기존의 시작 전 확인·전송 단위/목적지 확인·연결 복구·장비별 상태 보존·위험 동작 확인 계약을 유지합니다. 기능을 새로 발명하거나 기존 통신 엔진을 바꾸지 않습니다.

## 변경

V4 포리스트·라임 → 네이비·코발트·아이스 블루·오프화이트. 버튼, 선택 표시, 상태 배지, Dark 표면, 프로토타입 배경·모달 scrim·플러그인 UI까지 동기화했습니다. **원본 참고 캡처를 제외한 활성 디자인에 초록 팔레트를 남기지 않습니다.** 성공 역할은 인디고로 옮기고 이름·아이콘·실제 확인 상태와 함께 표시합니다.

문서의 새 단일 진입점은 `JETSONCONTROLLER_COBALT_FIELD_V5.md`이고 영구 가이드는 `COBALT_FIELD_STYLE_GUIDE.md`입니다. V4의 내용을 보존한 통합본이므로 구문서 없이 구현할 수 있습니다. START 문서, 프롬프트, 토큰, 17개 PNG, 프로토타입과 Figma 생성 데이터를 같은 세트로 동기화했습니다.

## 제공 이미지의 의미

`reference/last_shown_cobalt/`는 직전 답변 이미지 원본이고 `screens/`는 그 방향으로 소스에서 재생성한 이번 전체 상태입니다. 밝은 홈의 핵심 색상은 기존 PNG와 대조했습니다. 가려져 있거나 제공되지 않은 세부 상태색과 Dark 역할은 이 세트에서 명시적으로 완성한 값입니다.

앞선 생성형 홍보 이미지 두 장은 구현 사양에서 제외했습니다. 샘플 장치 사진·iOS 프레임·자동 AI 기능·근거 없는 진행률을 새 기능 요구로 가져오지 않습니다.

## 검증

이번 패키지 자체에 대해 로컬 51개 폭/글꼴 조합, 대표 상호작용 10개, 텍스트 대비 24쌍, Figma 코드 구문 및 mock 생성 경로를 다시 검사했습니다. 자세한 정합성·검증 결과는 `evidence/`를 따릅니다. 실제 앱·실기기·Figma 편집 결과는 여전히 별도 검증 대상입니다.
