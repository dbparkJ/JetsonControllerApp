# 참고 자료의 우선순위

`01_user_reference.png`~`08_user_reference.png`: 사용자가 처음 제공한 8장입니다. 기존 화면 구성과 기능 관찰의 근거이며 초록/청록색을 최신 앱 스타일로 채택하라는 뜻은 아닙니다.

`last_shown_cobalt/01-home-light.png`, `last_shown_cobalt/00-overview.png`: 직전 답변에 마지막으로 표시한 네이비·코발트 시안입니다. 이번 세트의 밝은 홈은 이 PNG와 픽셀 값이 동일합니다. 전체 시안은 `../screens/`와 `../design/tokens.json`을 기준으로 구현합니다.

중간 생성형 홍보 보드 두 장은 구현 사양에서 제외했습니다. 그 안의 장치 사진·초록색 배지·가짜 백분율/ETA·iOS 외형 등을 구현 기능으로 전용하지 않습니다.
