# 참고 자료 — 활성 배색 기준 아님

01~08은 사용자가 앞선 대화에서 제공한 원본 캡처를 그대로 보관한 자료다. `manifest.json`에 원본명과 SHA-256을 기록했다. 이 안의 초록 버튼·왼쪽 테스트 패널·검은 휴대전화 틀은 V7 앱에 복제하지 않는다.

`previous_v6/`의 6장은 직전 V6 로컬 시안이다. 새 PNG와 비교하는 목적이며 실제 앱 캡처가 아니다. V6의 따뜻한/차가운 섹션 배색을 활성 명세로 읽지 않는다.

이번 활성 배색은 상위 폴더의 `design/tokens.json`, `SLATE_HARMONY_STYLE_GUIDE.md`, `screens/`다. 원본 웹에 다시 접속하는 것은 선행 조건이 아니다.
