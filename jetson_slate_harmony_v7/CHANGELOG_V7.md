# V6 → V7 변경 기록

2026-09-09. 이 기록은 디자인 패키지 변경이며 앱 저장소 커밋 기록이 아니다.

| 부분 | V6 | V7 |
|---|---|---|
| 일반 표면 | cool / neutral / warm의 혼합 | 같은 회청색 계열의 base / soft / raised |
| 전체 바탕 | 따뜻한 오프화이트·여러 차콜 언더톤 | 하나의 낮은 색도 방향으로 정렬 |
| 현재 작업 | 옅은 표면·톤온톤 행동 | 옅은 표면 유지, 작은 주요 행동의 대비 복원 |
| 위험 목록 | 옅은 붉은 전체 패널 | 중립 전체 패널 + 작은 의미색 |
| 경계 | 공통 장식 경계 중심 | 장식 border와 controlBorder 분리 |
| 포커스 | 별도 고정 파랑 | 테마별 focusRing 토큰 |
| 상세/상태 범위 | 대표 상태 22개 | 32개로 다크 대응 확장 |
| 검증 | 지정 쌍 중심 | 렌더된 글자/아이콘 색 쌍 + 역할 계약 검사 |
| 연구 | 디자인/플랫폼 지침 중심 | 학술 연구 7편의 확인 범위·한계·적용 분리 |

새 고수준 기능·탭·통신·장비 명령을 추가하지 않았다. 샘플 데이터는 이전 시안에서 유지했다. 앱 코드에 적용할 때는 실제 최신 작업 트리를 먼저 확인한다.
